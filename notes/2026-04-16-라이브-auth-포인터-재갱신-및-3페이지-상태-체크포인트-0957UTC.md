## 추가 발견: bare live 브라우저 재검증에서 잡힌 실제 크래시
- live Playwright 디버그에서 페이지가 빈 화면이었고 `PAGEERROR Header is not defined` 를 직접 확인했다.
- 원인:
  - `src/app-shell.jsx` 의 `renderScreen()` 이 page modules 에 `Header={Header}` 를 계속 넘기고 있었지만,
  - 현재 shell/module 구조에는 `Header` 정의가 남아 있지 않았다.
- 조치:
  - `src/app-shell.jsx` 에서 불필요한 `Header={Header}` 전달 제거
  - `src/pages/layout-editor-page.jsx` 의 unused `Header` prop 제거
- 의미:
  - auth 포인터만 살아 있어도 앱이 빈 화면이면 버튼 자체가 노출되지 않는다.
  - 따라서 이 크래시 fix 가 bare live login/signup 실동작 복구의 직접 blocker 였다.
